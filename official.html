      このページについて

      AI開発ツール・SDKの公式リリースノートだけを集めたページです。現在 888本 を掲載しています。

      ニュース記事や解説記事は含みません。開発元が公式に出した更新情報＝一次情報のみを、/news から分離して掲載しています。「実際に何が変わったのか」を、解説を挟まずに確認するためのページです。

      追いかけている情報源

      CLIツール — Claude Code / Codex CLI / Gemini CLI / Ollama
      フレームワーク — LangChain / CrewAI / LlamaIndex / Dify / vLLM
      SDK — Anthropic SDK（Python / TypeScript）/ OpenAI SDK（Python / Node.js）/ Google GenAI SDK / MCP Python SDK
      仕様 — MCP Specification

      いずれも GitHub の公式リリースページから毎日自動で取得しています。

      このページの使い方

      • ツールで絞る — 左のサイドバーから特定のツールの更新履歴だけを追えます
      • 日付で絞る — 「先週何が更新されたか」をまとめて確認できます
      • カードをタップ — 更新内容の要約が開き、公式リリースページへ移動できます
