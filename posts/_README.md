# AI Navigator の記事の作り方

記事の原稿はこの `posts` フォルダに置く。**原稿はここの `.md` だけが正本**。文章・太字・見出し・画像は、この `.md` を直して保存すれば変わる（KURO に頼まなくていい）。

- このフォルダ: `C:\Users\suzuki.tomoya\Documents\Obsidian保管庫\ai-navigator\posts`
- 名前が `_` で始まるファイル（このファイル・`_ひな形.md`）は記事として読まれない

## 流れ

```
① 下書き    posts に .md を作る（published: が空のあいだは下書き）
② 確認      .md を Obsidian か Cursor で開いて直す
③ ローカル   記事プレビュー.bat をダブルクリック → 保存するたびに自動で作り直す → ブラウザを再読み込み
④ 本番      published: に公開日を書いて、KURO に「公開して」と言う
```

## ① 新しい記事を作る

1. このフォルダの `_ひな形.md` をコピーする
2. コピーの名前を `_` で始まらない名前に変える。英小文字・数字・ハイフンにして、slug と同じにしておくと分かりやすい（例: `ai-dokugaku.md`）
3. 頭の設定を書く（下の「頭の設定」）。最低限 `slug`・`title`・`checked` を入れる
4. 本文を書いて保存する

## ② ③ 直して確かめる

1. `ai-navigator` フォルダの `記事プレビュー.bat` をダブルクリックする
   - 場所: `C:\Users\suzuki.tomoya\Documents\Obsidian保管庫\ai-navigator\記事プレビュー.bat`
   - ブラウザで記事の一覧（`http://127.0.0.1:8080/articles/`）が開く。下書きには「下書き」の札と赤い帯が付く
2. `.md` を直して保存する。黒い窓に「更新しました 15:04:05（記事名）」と出たら、ブラウザを再読み込みする
3. 終わったら黒い窓を閉じる

## ④ 本番に出す

1. `published:` に公開日を書く（例 `published: 2026-11-05`）。今日より先の日付なら、その日までは下書きのまま
2. KURO に「〇〇の記事を公開して」と言う。本番への反映（GitHub への送信と配信の実行）は KURO がやる
3. 本番に出たら、KURO が Google に知らせる。サイトマップは API で送り直し、記事のURLは Search Console の「URL検査」から「インデックス登録をリクエスト」を押す（ここは画面からしか頼めない）

## 頭の設定

`.md` の一番上、`---` と `---` のあいだに書く。

| 項目 | 意味 | 例 |
|---|---|---|
| `slug` | URL の末尾。英小文字・数字・ハイフン。記事ごとに別の名前 | `ai-dokugaku` → `/articles/ai-dokugaku` |
| `title` | 記事のタイトル。本文に同じタイトルを書かない | |
| `description` | 検索結果に出る短い紹介文（100字前後） | |
| `eyebrow` | タイトルの上の小さな札 | `AI実録` |
| `answer` | 冒頭の「先に結論」の囲みに出す答え。本文に同じ文を重ねて書かない | |
| `published` | 公開日。**空なら下書き** | `2026-11-05` |
| `checked` | 内容を確かめた日。「確認日」として出る | `2026-10-31` |
| `pr` | 広告（アフィリエイト）を含むなら `true`。【PR】表記が出る | `false` |
| `sources` | 出典。`title`（名前）と `url` を並べる。無ければ `sources:` だけ | |

## 本文の書き方

| 書きたいもの | 書き方 |
|---|---|
| 太字 | `**大事な言葉**` |
| 大見出し（目次に出る） | `## 見出し` |
| 小見出し | `### 見出し` |
| 箇条書き | `- 内容` |
| 番号付き | `1. 内容` |
| リンク | `[表示する文字](https://example.com/)` |
| 写真を入れる前の枠 | `【画像: 何の画面か】` |
| 写真 | `![説明](https://…)` か `/assets/…`。写真のファイルを本番に置くのは KURO に頼む |
| 表 | `\| 項目 \| 内容 \|` の形（このファイルの表と同じ） |

- **目次**は `##` の見出しから自動で作られる
- **よくある質問**: `## よくある質問` の下に `### 質問` と、その答えの段落を書くと、検索や AI 向けの「質問と答え」のデータも自動で作られる

## うまくいかない時

- **黒い窓に「〇〇.md の 8 行目」と出た**: その行の書き方が間違っている。直して保存すれば作り直される（直すまでは前のページが残る）
- **一覧に記事が出ない**: ファイル名が `_` で始まっていないか、`.md` になっているかを見る
- **プレビューが開かない**: 黒い窓の文を KURO に貼る
